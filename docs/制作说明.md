# 《第四声回响》制作说明与复现指南

> 面向评审与本组复现：本项目为 AIGC 影像，不产出传统"代码"，创作资产全部以 Markdown 文档托管于本仓库。

## 一、成片规格

| 项目 | 数值 |
|---|---|
| 总时长 | 210 秒（3 分 30 秒） |
| 镜头数 | 35 镜 × 6 秒 |
| 画幅 | 16:9 |
| 生成方式 | 可灵只生成**无声画面**；对白、字幕、聊天窗口、Echo·语镜界面、游戏文字由剪映 / After Effects **后期合成** |

## 二、创作流水线（四 Agent）

```
编剧 Agent → 预审 Agent → 素材生成 Agent → 粗剪 Agent
```

各 Agent 系统提示词见 `docs/Agent提示词/`，创作流程与产物均写入 `docs/迭代记录.md`。

## 三、制作分工

- **真人实拍：** 主角色（周奕 / 母亲）真人实拍锁脸，保证面部稳定一致，规避 AI 换脸 / 融脸风险。
- **AI 生成（可灵）：** 仅用于"1998 年被辞退日"想象段落（图生视频），及部分空镜 / 屏幕特写，**不生成人脸特写承担叙事**。
- **后期合成（剪映 / After Effects）：** 对白字幕、聊天窗口、Echo·语镜网页、游戏界面、片尾文案，全部逐字核对后合成。
- **35 镜分镜提示词：** 见 `docs/分镜/35镜分镜_可灵提示词.md`，每镜含正向提示词、全局负向提示词、后期 / 声音与连续性约束。

## 四、复现步骤

1. 读 `docs/剧本/短片剧本_终稿.md` 确定故事与对白；
2. 读 `docs/分镜/35镜分镜_可灵提示词.md` 逐镜生成无声画面素材；
3. 读 `docs/Agent提示词/素材生成Agent.md` 核对素材需求与负向提示词；
4. 用剪映 / After Effects 按 `docs/Agent提示词/粗剪Agent.md` 的时间线规则合成对白、字幕与界面；
5. 对照 `docs/剧本/人物设定卡.md` 校验人物与场景一致性。

## 五、AI 使用声明（如实声明）

- **使用的 AI 工具：** 可灵（AI 视频生成）、剪映 / After Effects（AI 辅助后期合成）、豆包（创作 Agent 协作、文档整理）。
- **用途与范围：** 可灵仅用于"1998 年被辞退日"主观想象段落及部分屏幕 / 空镜的画面生成；剪映 / After Effects 用于字幕、聊天 UI、Echo·语镜界面与游戏文字合成；豆包用于四份创作 Agent 提示词的整理与迭代记录维护。
- **人工核验：** 剧本、人物、分镜与全部关键对白为团队原创设计与多轮迭代（见迭代记录）；所有出现在画面中的关键文字（对白字幕、聊天消息、报名表、Echo·语镜文本、片尾）均人工逐字核对，不由随机生成承担。
- **原创性：** 角色为 100% 原创设计，无可联想的网络人脸，规避肖像权与版权风险；项目知识产权归参赛团队所有。

## 六、原创性与开发边界说明

按赛事手册要求如实说明：本作品命题于 10/1 开幕式现场揭晓；创作过程中剧本、分镜、Agent 提示词与成片在本届赛事周期内完成并持续提交到仓库（Git 历史可查），参赛团队独立完成判断与实质创作。
